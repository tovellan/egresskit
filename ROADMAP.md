# Roadmap

The committed v0.3.0 scope is complete. Exact provider destination bindings,
declarative policy test suites, policy lint reports, and legacy IPv4 ambiguity rejection
are released with the core fail-closed policy gate. There is no unreleased feature
commitment or known implementation item in this roadmap.

Future work, if accepted, will be tracked as a scoped GitHub issue. EgressKit will not
become a payload classifier, content scanner, consent ledger, or compliance
certification tool.
