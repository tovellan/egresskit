# Roadmap

The committed v0.5.4 scope is complete. Forward-only public commit identity controls,
strict document parsing, exact provider destination bindings, safe serialization errors,
optional HTTPX transports, declarative policy test suites, policy lint reports, and
deterministic explanations are released with the core fail-closed policy gate. There is
no unreleased feature commitment or known implementation item in this roadmap.

Future work, if accepted, will be tracked as a scoped GitHub issue. EgressKit will not
become a payload classifier, content scanner, consent ledger, or compliance
certification tool.
