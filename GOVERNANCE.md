# Governance

EgressKit uses a maintainer-led model. Maintainers review contributions, manage releases,
and protect the security and compatibility boundaries described in the documentation.

Routine changes are accepted through reviewed pull requests with passing checks. Changes
to policy semantics, the receipt schema, supported versions, governance, or the threat
model require explicit maintainer approval and release notes.

Maintainers may be added after sustained, constructive contributions and demonstrated
care with the security boundary. Inactive maintainers may step down or be removed after
a documented project discussion. No paid support or commercial influence is implied by
maintainer status.
